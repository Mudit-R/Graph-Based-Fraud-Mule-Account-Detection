Technical Deep Dive: Why Hybrid GAT + XGBoost Beats Standalone XGBoost

Production System Architecture

1. Maximum Total Fraud Capture (Recall)

86.07% vs 83.43%

In banking and AML compliance, missed fraud (False Negatives) is the most expensive operational risk. Mule accounts intentionally maintain normal-looking balance profiles to bypass tabular rules. Adding GAT graph attention embeddings recovers hidden mule rings that standalone XGBoost completely misses.

2. High-Order Relational Feature (P_GAT)

ROC-AUC 0.9129

Tree models only make orthogonal splits on single continuous variables (e.g. balance_drain > 0.98). GAT computes multi-hop attention weights ($\alpha_{ij}$) across complex transaction paths, compressing global network topology into a single feature $P_{\text{GAT}}$ fed directly into XGBoost.

3. Focal Loss Probability Calibration

Precision@100 = 75%

Standalone GNNs trained with Focal Loss suffer from probability output compression, hurting standalone threshold precision. Stacking $P_{\text{GAT}}$ into XGBoost calibrates probability scores while maintaining 75% Precision@100 for manual investigation alert budgets.
